# Architecture
## Direção aprovada
Monólito modular local. React/TypeScript + Remotion (mesma versão dos pacotes), processo Node local, SQLite via driver compatível verificado; Python em ambiente virtual para Kokoro e Faster Whisper; FFmpeg/ffprobe como executáveis locais. Seleção de versões e driver no preflight, sem assumir versões ou GPU. UI local em 127.0.0.1. Sem Docker obrigatório, nuvem, autenticação de SaaS ou broker externo. Interface de processo por CLI/JSON validado; sem shell interpolado.
## Componentes e dependências
UI -> Application/Orchestrator -> domínio Project/Scene/Asset/Claim/Job -> ports (Research, Script, Image, TTS, Alignment, Render, Export) -> adapters (Codex humano/CLI autorizado, importação, Kokoro, Whisper, Remotion, FFmpeg, SQLite, filesystem). Domínio não depende de React, SQLite nem subprocessos. Codex não é um serviço embutido com credenciais capturadas: agente opera manifests e scripts pelo cliente oficial; integração CLI apenas se suportada, sem presumir API programática incluída. Operações determinísticas não usam LLM. Sem novos MCPs por padrão; plugin oficial Remotion é preferido se disponível. Não tornar OpenChatCut obrigatório.
## Pipeline
TOPIC -> RESEARCH -> BRIEF -> SCRIPT -> STORYBOARD -> ASSETS -> VOICE -> ALIGN -> EDIT -> PREVIEW -> QA -> RENDER -> EXPORT -> HUMAN_APPROVAL. Estado de job: pending/running/succeeded/failed/blocked/canceled/stale; atomic output e verificação de hash antes de succeeded. Revisão editorial pode invalidar downstream por DAG. Alterar áudio invalida alinhamento/timeline/mix; trocar asset invalida cenas dependentes; mudar título não renderiza vídeo novamente. Retry limitado, resume e cancelamento seguro; um render pesado por vez.
## Estrutura candidata
apps/studio (UI local e controller); packages/domain (schema/validation); packages/pipeline; packages/motion; packages/media; scripts (preflight/QA); tests; docs; evidence. Simplificar se houver alternativa comprovada; não criar infraestrutura vazia. Media root fora de Git: projects/<id>/assets, audio, manifests, preview, render, export, logs. Paths resolvidos dentro de root. SQLite mantém metadados, não blobs grandes.
## Render
Composições parametrizadas; frames inteiros baseados em fps; derive áudio e legendas do mesmo clock; evitar render de cena isolada que quebre transições, re-render segmentos com handles ou composição integral conforme benchmark. Prévia reduzida e final 1080p/30fps H.264 yuv420p/AAC, 48kHz, faststart quando suportado. CPU fallback, GPU só comprovada. Armazenamento configurável; SSD temporário se disponível, HD externo para arquivo, sem mover dados sem permissão.
## Economia de tokens
Luna se disponível, configuração Max preferida pelo usuário mas não pressupor menor consumo; registrar modelo/esforço real e limites observáveis. Contexto mínimo, instruções estáveis, leitura seletiva, cache por hash e deltas; sem múltiplos agentes; não comprar créditos nem tentar contornar cotas. Se a conta não permitir ferramenta, marcar BLOCKED ou usar fallback autorizado. Nenhum trabalho em background prometido.
