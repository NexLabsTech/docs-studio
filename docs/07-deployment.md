# Deployment
Windows local only. Discover current environment before install. Prefer project-scoped Node deps, Python venv and official tools, avoid global modifications/admin. Pin versions after qualification; document install, run, stop, update, uninstall and rollback. Use localhost; no firewall changes or tunnel. No cloud account, billing or publishing. Preflight must not install full app; only scoped qualification artifacts. App deploy later: launch command/shortcut, configurable media path, health check and local end-to-end playback/export. Confirm restart/resume and backup/restore. Git branch/PR with CI if remote authorized and accessible; if no remote, local evidence and BLOCKED on remote gate. No fabricated checks. Do not enable paid CI. No merge before independent APPROVED and checkpoint delta promotion by auditor. For initial empty repository, bootstrap docs-only base first, record SHA, then WO branch; if Git identity/remote unavailable do not invent identity. Never overwrite existing repo or create public remote without authorization.
