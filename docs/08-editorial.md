# Editorial & Creative Bible
## Direction
Mega Engineering, investigative cinematic documentaries en-US; US first, Canada/UK/Australia secondary. Angle: human ingenuity, cost, constraints, failure, surprising solutions. Not lectures or generic AI slides. Target themes: 30% megaprojects; 25% failed/abandoned; 20% impossible solutions; 15% future cities; 10% giant machines. Hypotheses, review with data. Candidate pilot Kansai airport. Additional candidate topics: Netherlands flood protection, Channel Tunnel, Dubai artificial islands, Bosphorus crossings, Burj Khalifa, TBMs, Hoover Dam, desert rail, Venice MOSE. Verify each independently; no unsupported dollar figures.
## Research and factual standard
Research primary sources (operator, government, engineering reports, scholarly papers), triangulate material claims with independent reputable sources where feasible. Ledger claim ID, exact assertion, date, source URL, publication/access date, relevant excerpt or locator, unit/currency/year, uncertainty, status. Conflicting claims must be qualified or excluded; source absence blocks factual publication. Use original narration/analysis and avoid copied transcripts. Do not present AI reconstructions as archival imagery; scene-level labeling and YouTube disclosure checklist. Do not invent precise geography or diagrams; build from verified data. If simulation, label conceptual/not to scale as appropriate.
## Duration and narrative
Adaptive: compact 5–8 min, default 8–12, deep 12–18, special 18+ only if justified. No padding for midrolls. Rough 125–165 words/minute with pauses; actual duration based on rendered voice. Opening 0–5s striking truthful visual/claim; 5–30s promise and stakes; context -> obstacles -> discoveries -> climax -> answer/consequences. No long logo intro, early subscription demand or bait-and-switch. Use micro-hooks on genuine changes in stakes, not repetitive cliffhangers. Visual rhythm as needed, roughly 4–7s per shot as hypothesis; let key shots breathe. 3–6 generated images/minute is initial planning range, not quota; use original graphs, diagrams, animation and varied compositions.
## Hook library (templates only; fact-check before use)
- Impossibility: “They said it could never be built. Then engineers found a way.”
- Hidden cost: “The most expensive part of this project was never supposed to exist.”
- Critical decision: “One engineering decision changed the future of an entire city.”
- Forgotten project: “Hidden beneath this mountain is a project almost nobody remembers.”
- Paradox: “To keep this city above water, engineers had to build beneath it.”
- Scale: “This machine is so large that an entire factory was built around it.”
## Visual style
Cinematic Industrial: #0B1017 Obsidian, #142C3D Deep Ocean, #40C5D5 Cyan, #E9A23B Amber, #E8E6E1 Ivory. Barlow Condensed / Inter / IBM Plex Mono, verify licenses and use local fonts. Steel, concrete, fog and natural lighting; avoid generic AI gloss. Establishing shots, technical reveals, maps, scale comparisons, indicator overlays, data animation, historic sequences and hero shots. Source-backed consistent geometry; visual continuity; controlled color grading, restrained effects. Original SVG hand/pointer, arrows, annotations; not every shot needs an effect.
## Motion components (MVP candidates, each with schema/test)
CinematicCamera, ParallaxScene, AnimatedHand, FocusArrow, ObjectHighlight, TechnicalBlueprint, AnimatedMap, ScaleComparison, NumberCounter, HistoricalTimeline, DocumentReveal, KineticTypography, DynamicCaptions, CinematicGrade, FilmGrain, AtmosphereFX, SceneTransition, SoundTrigger, AudioDucking, EndScreen. Deterministic motion, no random without seed; data/coordinate validation; no fabricated maps. Only implement essential variants for pilot and prove reuse. Use accessible contrast and safe margins.
## Sound design
Narration (Kokoro en-US, select after listening), music, ambience, Foley, cinematic hits. Prefer original procedural sound assets via DSP/synthesis, plus YouTube Audio Library when appropriate; no unverified assets, voice impersonation or copied melodies. License ledger even for generated assets. Ambient sounds support scene and avoid false claims of real field recording. Intentional silence. Duck music under narration, smooth fades, avoid clipping; mix target -14 LUFS-I +/-2, <=-1 dBTP reference. Music/voice licensing and disclosure review each time.
## YouTube package & audience learning
Three original title/thumbnail pair proposals; clear dominant subject, no deceptive promises, little text, mobile-readable. Description with context/sources/disclosure/attribution, SRT en-US, chapters if applicable (timestamps validated). Manual publishing only. Use accurate account country (Brazil), English language. Initial target two videos/week conditional on quality/capacity; no auto scheduling. Analyze CTR (experimental 5–8%), 30s retention (>=70%), avg viewed (45–55%), US share (>=40%); these are hypotheses, not guaranteed benchmarks. Compare like duration/traffic source; revise after 5–10 episodes if enough data, no unsupported causal inference. No analytics API needed; manual export/import possible. Future social shorts use verified scene boundaries/focal points but no vertical production in MVP.
