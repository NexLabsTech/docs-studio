# UI/UX
Local minimal dashboard, no account screens. pt-BR control interface; produced content en-US. Dark Industrial palette (docs/08), legible typography, responsive enough desktop; no elaborate visual editor required. Views: Projects/new, Brief & Sources, Script & Storyboard, Assets & Audio, Preview/QA, Render & Export. Show stage, real progress, last error, pending review, storage path/estimate. Controls: new project, import/replace asset, select voice, review claims, preview, run/retry/cancel stage, render, export package. Confirm irreversible cleanup and never silently overwrite export. Show missing ImageGen/license/quota as blocker/fallback with clear remedy. No publish button, social tab or fake progress. Keyboard access, focus, labels, contrast, readable errors. UI E2E verifies actual states, not just screenshots. Future vertical capabilities not in UI.
