# Test & Benchmark Plan
## CORE (somente smoke isolado)
Inventário Windows, CPU/GPU/RAM/disco, Node/npm/Python/Git, ffmpeg/ffprobe, Codex/modelo/plugins; versão, fonte, arquitetura, licença. Usar diretório temporário dedicado. Provas: render Remotion 5–10s fixture sintética; TTS 1 frase en-US; Whisper timestamps em CPU; ffmpeg mix/encode e ffprobe; SQLite create/read/transaction/reopen em fixture; geração de imagem uma amostra apenas se ferramenta oficialmente acessível sem cobrança adicional. Caso não haja ImageGen, documentar fallback importação e testar fixture. Não instalar SDKs grandes automaticamente se espaço insuficiente; verificar impacto, pedir aprovação se privilégios/alterações globais necessárias. Provas podem ser BLOCKED; não fingir êxito.
## MVP
Unit: schema, timebase, paths, state transitions, invalidation/cache, claim/asset/license validation, metadata export. Integration: SQLite restart/migration, actual TTS/alignment/renderer, audio mix, interrupted job, cancellation, missing assets, invalid file/timeout/disk-full simulation. UI/E2E: new project -> review -> preview -> render -> export; offline local flow after asset acquisition, untrusted inputs rejected. Regression: fixed fixture, golden metadata/perceptual tolerance (not binary equality for nondeterministic encoders). Security: traversal/UNC/reparse, injection, host/origin, no secret leakage, no external paid requests. CI: unit + lint + typecheck + build + applicable integrations with synthetic assets; Windows native local real media validation; free hosted CI only if eligibility proven, no paid runner. Manual QA: facts/source quality, audio pronunciation, visual identity, reconstruction disclosure, transitions, pacing, originality, captions, export playback.
## Benchmark
Inventory + tool versions + settings + fixture hashes + measured wall time/peak RAM/temp disk/output size; run 3 repetitions if feasible, record median/range and cold/warm separately. Baseline 10s at 1080p, then 60s representative fixture, then full pilot. Report render factor = wall seconds / video seconds, TTS factor, align factor, free space, cache hit/miss and speedup. Test CPU baseline, GPU comparison only if available. Candidate initial budgets (PROPOSED, calibrate on hardware): no crash/OOM, no swap thrashing, 60s fixture completes, temp space estimate >= measured peak + margin; target render <= 10x real-time, peak memory <= 75% installed RAM, no hard time promise. Disk floor = estimated peak + safety margin; choose margin based on measurement and OS needs. If performance fails candidate target, document tradeoff and seek ratification; no lowering quality silently. MVP audio reference -14 LUFS-I +/-2, true peak <= -1 dBTP; review intelligibility and silence intentionally. Validate frame/audio duration within declared codec/frame tolerance, SRT monotonic, no missing sources/rights. Capture evidence, don't claim 100% coverage unless actually measured.
