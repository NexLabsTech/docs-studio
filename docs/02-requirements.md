# Requirements
IDs estáveis; critérios objetivos em DoD e WOs subsequentes.
| ID | Requisito |
|---|---|
| R01 | Execução local Windows, conta Codex existente, nenhuma nova assinatura ou API paga; instalações oficiais e elegibilidade verificadas. |
| R02 | Pauta com fonte verificável, claim ledger, datas/unidades, distinção entre fatos, estimativas, hipóteses e reconstruções. |
| R03 | Roteiro original en-US com gancho factual, arco narrativo, duração justificada, pronúncia e ausência de preenchimento artificial. |
| R04 | Storyboard semântico com timing, asset IDs, enquadramento, focos, efeitos e fontes; continuidade visual. |
| R05 | Image provider preferencial integrado ao Codex somente se capacidade e acesso sem cobrança adicional comprovados; fallback importação manual de imagens ChatGPT dentro da franquia; nenhuma chamada paga automática. |
| R06 | Kokoro TTS local en-US, escolha de voz autorizada, controle de pausas e pronúncia; Faster Whisper local com timestamps e revisão contra roteiro. |
| R07 | Biblioteca Remotion de motion graphics originais; efeitos intencionais por cena, não templates idênticos. |
| R08 | Cinco trilhas de áudio, efeitos procedurais próprios e/ou licenciados, ducking, mix e registro de licença. |
| R09 | Orquestração persistente, cache por hash, execução idempotente, retomada, revisão e render seletivo. |
| R10 | UI local para criação, etapas, revisão, substituição de assets, prévia, render e exportação. |
| R11 | MP4 H.264/AAC 1920×1080 30fps, SRT en-US, 3 propostas título/thumbnail, descrição, capítulos quando adequados, fontes e indicação de disclosure. |
| R12 | QA automatizado de schema, arquivos, segurança, sincronização, áudio, resolução/duração; revisão editorial humana obrigatória. |
| R13 | Localhost apenas, arquivos privados, caminhos protegidos, nenhum serviço pago, nenhuma publicação automática. |
| R14 | SQLite para metadados e estados; mídia no filesystem, backup/restore verificáveis. |
| R15 | Perfis de armazenamento configuráveis, estimativa de espaço, render temporário e limpeza segura apenas de cache autorizado. |
| R16 | Timeline neutra quanto à proporção: safe zones, focal point, tags narrativas, word timestamps e scene boundaries; não implementar vertical no MVP. |
| R17 | Analytics manual/importação local autorizada para futuras decisões; não exigir OAuth ou YouTube API no MVP. |
| R18 | Economia de contexto: agente principal, manifests compactos, cache, deltas, sem LLM para processamento determinístico. |
| R19 | Evidências de engenharia versionadas, testes, lint, typecheck, build, benchmark, instalação local e auditoria antes de declarar completo. |
